# El Asador Margarita Ranch Grill

Customer-ready restaurant website built with React 19, TypeScript and Vite.

## Run locally

Use Node.js 22 or newer. Run `npm ci`, then `npm run dev`. Run `npm run build` for the production build and `npm run lint` for the TypeScript check.

## Included

- Responsive editorial restaurant design with sticky navigation and mobile actions.
- Full menu and prices transcribed from the restaurant's published menu image.
- Opening hours transcribed from the restaurant's published hours image.
- Verified address, phone, WhatsApp, Instagram and Google Maps links.
- Actual restaurant patio photograph supplied through the public Google Maps listing.
- Accessible semantic structure, keyboard-friendly gallery dialog, visible focus and reduced-motion support.
- Restaurant metadata and structured data for search engines.

The active website is in `src/App.tsx`, with styles in `src/index.css`. The `dist` directory contains the deployable production build.
